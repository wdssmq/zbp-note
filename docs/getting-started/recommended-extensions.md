# 推荐扩展

接受工作区推荐扩展后，`.vscode/extensions.json` 中定义的扩展会自动安装。

此列表可能会发生变化。

- [Foam for VSCode](https://marketplace.visualstudio.com/items?itemName=foam.foam-vscode)
- [Markdown All In One](https://marketplace.visualstudio.com/items?itemName=yzhang.markdown-all-in-one)
- [Prettier](https://marketplace.visualstudio.com/items?itemName=esbenp.prettier-vscode)

## 其他功能扩展

这些扩展未在 `.vscode/extensions.json` 中定义，但其他用户使用后发现它们与 Foam 配合良好。

- [Emojisense](https://marketplace.visualstudio.com/items?itemName=bierner.emojisense)（在 Markdown 文件中提供表情符号自动补全和建议）
- [Markdown Emoji](https://marketplace.visualstudio.com/items?itemName=bierner.markdown-emoji)（添加 `:smile:` 语法支持，并与 Emojisense 配合为该语法提供自动补全）
- [Mermaid diagrams Support](https://marketplace.visualstudio.com/items?itemName=MermaidChart.vscode-mermaid-chart)（为 Markdown 中的 Mermaid 代码块添加语法高亮，并在 Markdown 预览中渲染 Mermaid 图表）
- [Excalidraw whiteboard and sketching tool integration](https://marketplace.visualstudio.com/items?itemName=pomdtr.excalidraw-editor)（直接在 VS Code 中创建和编辑手绘风格的图表与草图）
- [VSCode PDF Viewing](https://marketplace.visualstudio.com/items?itemName=tomoki1207.pdf)（无需外部应用，直接在 VS Code 中查看 PDF 文件）
- [Project Manager](https://marketplace.visualstudio.com/items?itemName=alefragnani.project-manager)（轻松在多个项目和工作区之间切换）
- [Markdown Extended](https://marketplace.visualstudio.com/items?itemName=jebbs.markdown-extended)（提供额外格式选项和扩展 Markdown 语法支持；请禁用 `kbd` 选项，因为它会与 wikilink 冲突）
- [GitDoc](https://marketplace.visualstudio.com/items?itemName=vsls-contrib.gitdoc)（自动执行 Git 提交，便于管理版本和备份笔记）
- [Markdown Footnotes](https://marketplace.visualstudio.com/items?itemName=bierner.markdown-footnotes)（为 VS Code 内置 Markdown 预览添加脚注语法 `[^footnote]` 支持）
- [Todo Tree](https://marketplace.visualstudio.com/items?itemName=Gruntfuggly.todo-tree)（扫描工作区中的 TODO、FIXME 和其他注释标签，并在树视图和编辑器装订线中显示）
