# 键盘快捷键

下面是一些编辑笔记时非常实用的键盘快捷键。

如果能在预览面板中查看结果，使用体验会更好。请运行 `Markdown: Open Preview to the Side` 命令。

你可以使用名称或 ID 在设置（File > Preferences > Keyboard Shortcuts）中查找每个快捷键，查看它在系统中的绑定方式，并根据需要进行修改。

| 快捷键         | 名称            | ID                                      | 扩展                | 用途                              |
| -------------- | --------------- | --------------------------------------- | ------------------- | ----------------------------------- |
| `alt+c`        | \-              | markdown.extension.checkTaskList        | Markdown All in One | 切换 TODO 项。                     |
| `cmd+b`        | \-              | markdown.extension.editing.toggleBold   | Markdown All in One | 将选中内容设为粗体。              |
| `cmd+i`        | \-              | markdown.extension.editing.toggleItalic | Markdown All in One | 将选中内容设为斜体。              |
| `ctrl+shift+f` | 格式化文档      | editor.action.formatDocument            | Base                | 格式化表格。                      |
| `cmd+shift+f`  | 查找文件        | workbench.action.findInFiles            | Base                | 在工作区中搜索。                  |
| `cmd+shift+e`  | 显示资源管理器  | workbench.view.explorer                 | Base                | 显示文件资源管理器。              |
| `cmd+alt+v`    | 粘贴图片        | extension.pasteImage                    | Paste Image         | 从剪贴板粘贴图片。                |
