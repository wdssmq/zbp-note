# 使用源代码管理同步笔记

源代码管理是一种精确管理文件目录历史记录和内容的方式。
它通常用于程序代码，同样也非常适合管理笔记。

将更改提交到源代码管理有很多（甚至太多）方式：

- 使用 VS Code 自带的 Git 集成
  - 快速简单的方式是在编辑文件后使用 `Git: Commit All` 命令。默认的 Foam 工作区设置会暂存所有更改并将其同步到远程仓库：
- 使用 GitDoc 实现[[automatic-git-syncing]]
- 使用你喜欢的任何方式（CLI？）
