### `main.php` 保存配置

```php
// $suc 只是个人习惯，大部分时候都用不上
$act = GetVars('act', 'GET');
$suc = GetVars('suc', 'GET');
if ($act == 'save') {
  // 安全验证↓这个很重要
  CheckIsRefererValid();
  foreach ($_POST as $key => $val) {
    if (substr($key, 0, 5) == 'read_') {
      continue;
    }
    $zbp->Config('APP_ID')->$key = trim($val);
  }
  $zbp->SaveConfig('APP_ID');
  // 重建模板，即使功能上不需要习惯性写上也不会损失什么
  $zbp->BuildTemplate();
  // 保存后给出操作成功的提示
  $zbp->SetHint('good');
  // 重定向一次页面，不然地址栏会是 main.php?act=save&csrfToken=cbb7ce8bd23
  // 一是视觉上乱，二是刷新页面会有重复提交的提示
  Redirect('./main.php' . ($suc == null ? '' : "?act={$suc}"));
}

```

对应的 HTML 表单为：

```php
<form action="<?php echo BuildSafeURL('main.php?act=save'); ?>" method="post">

</form>

```
