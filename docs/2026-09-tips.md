### `main.php` 保存配置

```php
// $suc 只是个人习惯，大部分时候都用不上
$act = GetVars('act', 'GET');
$suc = GetVars('suc', 'GET');
if ($act == 'save') {
  CheckIsRefererValid();
  foreach ($_POST as $key => $val) {
    if (substr($key, 0, 5) == 'read_') {
      continue;
    }
    $zbp->Config('APP_ID')->$key = trim($val);
  }
  $zbp->SaveConfig('APP_ID');
  $zbp->BuildTemplate();
  $zbp->SetHint('good');
  Redirect('./main.php' . ($suc == null ? '' : "?act={$suc}"));
}

```
