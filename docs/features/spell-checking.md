# 拼写检查

VS Code 有许多拼写检查扩展。

VS Code 最受欢迎的拼写检查器是 [Code Spell Checker](https://marketplace.visualstudio.com/items?itemName=streetsidesoftware.code-spell-checker)。

我们还很喜欢 [LTeX](https://marketplace.visualstudio.com/items?itemName=valentjn.vscode-ltex&ssr=false#overview)，它相对更重一些，但提供了额外功能。

另一个流行的扩展是 [Spellright](https://marketplace.visualstudio.com/items?itemName=ban.spellright)，但请注意，有报告称它与 `vscode-markdown` 扩展不兼容（参见 https://github.com/foambubble/foam/issues/1068）。
